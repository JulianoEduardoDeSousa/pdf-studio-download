# PDF Studio — download para Windows

Editor de PDF: edite textos existentes, adicione caixas de texto, preencha formulários
(campos de texto, caixas de seleção, botões de rádio e listas) e assine documentos.
Recursos opcionais de IA (OCR, reescrita e preenchimento inteligente) com a sua própria chave de API.

## Como instalar
1. Baixe **[PdfStudio-Setup.exe](https://github.com/JulianoEduardoDeSousa/pdf-studio-download/releases/latest/download/PdfStudio-Setup.exe)**.
2. Execute o instalador. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Não precisa de administrador: o app é instalado só para o seu usuário. Marque "Abrir com" durante a instalação para abrir PDFs direto pelo Explorador.

Requisitos: Windows 10 ou 11, 64 bits.
